# jyanken_app_drills

じゃんけんアプリを穴埋め問題で作ってみよう！

## 穴埋め問題案

1. ボタンを押してテキストを変える：ボタンを押すと　ボタンの上のテキストが　押された！　に代わる
2. ボタンを押すとランダムにグーチョキパーが表示される：ボタンを押すと　ランダムなテキストが表示される　自分で設定できる
3. グーチョキパーで勝敗判定を設定させる：9通りのパターンを網羅させて、正しい結果になるようにさせる。
